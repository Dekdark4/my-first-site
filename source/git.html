Git / GitHub

Введение

Git — это система контроля версий. Звучит сложно, но на деле это просто незаменимый инструмент любого разработчика. Так что же это такое?

Представь самую настоящую машину времени. Когда ты создаёшь проект — сайт, игру, программу — тебе нужно сохранять разные его версии: бэкапы на случай ошибки, рабочие варианты, эксперименты. Раньше для этого приходилось вручную копировать папки с названиями вроде «Проект_финал_2_точно». Git делает то же самое, но автоматически и гораздо умнее.

С его помощью ты можешь делать со своими «сохранениями» всё что угодно: перемещаться между ними, удалять лишнее, объединять разные идеи и даже возвращаться назад, если что-то пошло не так. Это не просто инструмент — это твой второй шанс и «мультиплеер» для кода, где вы с другом можете работать над одним проектом, не мешая друг другу.
